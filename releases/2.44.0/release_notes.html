Release notes¶

2.44.0¶

  • New Features
    • Torch

      • Support quantizing over multiple channel axes (41d7f97)

      • Support AdaScale for MoE top-k routers (d7f5f4b)

  • Bug fixes and Improvements
    • ONNX

      • Optimize sampling efficiency in AdaScale (9cc3764, 41d4f61)

      • Fix unsafe quantizer tying behavior for unquantized concat inputs (72ef63f)

      • Optimize param quantizer fold memory footprint (375709f)

      • Improve AdaScale progress logging (a122660)

      • Improve SeqMSE progress logging (2740013)

      • Reduce SeqMSE CPU memory usage during activation caching (7d44844)

      • Log effective quantizer name in set_tensor_precision API (1b0158d)

      • Allow running SeqMSE for QuantSims with tf-enhanced QuantScheme (1878a56)

      • Fix detection of non-affine RMSNorm followed by Mul op (c34be4c)

    • Torch

      • Fix slowdown in AdaScale from global allow_mutation_on_saved_tensors flag (416501a)

      • Propagate output quantizers for all grid-equivariant op types (ceff47c)

      • Preserve zero-point shift when restoring affine quantizers (677f753)

      • Fix blockwise export with singleton output channels (c998316)

      • Preserve channel slices when merging calibration histograms (827cd4e)

      • Fix unsafe tying of output quantizers consumed by multiple ops (50abd95)

      • Fix AdaScale linear block quantization weight scaling (d913a33)

      • Prevent HTP bias overflow for zero-weight channels (704d290)

      • Optimize memory usage when re-deriving quantization scale from weights (e0122dc)

      • Always keep int32 bias quantizer parameters in float32 (a5070d1)

      • Fix loading encodings for tied quantizers (f8794fc)

      • Skip instantiating quantizers for integer tensors (5891c5d)

    • Common

      • Propagate encodings through float-to-float casts during export (ec6ebb6)

      • Fix broken API rendering in docs (16854ba)

      • Update docs theme (6c6055e)

  • Deprecations
    • Torch

      • Remove save_checkpoint and load_checkpoint in favor of direct pickle usage (253b7c0)

      • Remove check_accumulator_overflow (253b7c0)

      • Remove compute_encodings_for_sims (253b7c0)

2.43.0¶

  • New Features
    • ONNX

      • Support bfloat16 graphs in QuantizationSimModel, including calibration, SeqMSE, AdaScale, AdaRound, AMP, cross-layer equalization, BatchNorm folding, SpinQuant, QuantAnalyzer, layer output dumping, PSNR/lite-mp evaluation, and LoRA adapters in aimet_onnx.peft (ff4f611, 901c4cf, 76e0b47, 28ace30, 36190d4, bea0d4e, fee0d31, 66e6e3b, 606ee2f, 46bbd5d, a3f7904, cfa85a5, c507684, e4092b7, e572b36, 7b28de8)

      • Quantize If branches in QuantizationSimModel behind the subgraph flag (e4f515b, 3019fd1, 6a25cb6)

  • Bug fixes and Improvements
    • ONNX

      • Redesign aimet_onnx.experimental.lora: adapters are now prepared with aimet_onnx.peft.load_lora_adapters instead of prepare_lora_onnx, and quantized with a smaller, renamed helper set (f371064)

      • Skip unsafe encoding tying through Split (980d9d7)

      • Refactor to_onnx_qdq() helpers to use the onnx_ir API and fix a missing helper export (fd36575, f909daf)

      • Don’t optimize frozen quantizers in AdaScale (9ca2127)

      • Add strict option to encodings_to_onnx_qdq to skip unmatched encodings instead of raising (78f0907)

      • Tie Scan body inputs to their boundary quantizers (94ad369)

    • Torch

      • Fix clipped QDQ scale gradients with zero-point shifts (aa91641)

    • Common

      • Upgrade onnxsim to 0.7.0 (4867813)

      • Windows (x64/arm64) and macOS aimet-onnx wheels are now available on PyPI (81d3a20)

      • Update quantization recipe docs for Gemma 4 and Qwen3-VL (af9c406)

      • Pin torch<2.15 and torchvision<0.29.2 in released wheels to avoid pulling CUDA 13 builds incompatible with CUDA 12.x drivers (cd33832)

      • Always save models with external data regardless of size (fe922f8)

    • Common

      • Fix import-time assertion error with onnx<1.18 (3c937bc)

      • Delete unused legacy quantsim config files (093e72f)

      • Use configure_llm API in GenAI Lab (bbb2c97)

      • Fix Qwen 3.5 export on transformers >= 5.15 in GenAI Lab (1d669a6)

      • Export dynamo backbones with one torch.export mode per torch version in GenAI Lab (7d13097)

      • Rename GenAI Lab linear-attention state I/O to conv_state / recurrent_state (e078c16)

      • Fix GenAI Lab relative imports (6c0d5d3)

      • Document v2.1.0 encoding spec and fix broken AdaScale/SpinQuant doc snippets (38dc892, 191d51b)

  • Deprecations
    • ONNX

      • Move adascale, spinquant, llm_topology and llm_configurator out of aimet_onnx.experimental into top-level aimet_onnx. The old aimet_onnx.experimental.* import paths still work but emit a deprecation warning, and will be removed in AIMET 2.45 (94a2319)

    • Torch

      • Move adascale and spinquant out of aimet_torch.experimental into top-level aimet_torch. The old aimet_torch.experimental.* import paths still work but emit a deprecation warning, and will be removed in AIMET 2.45 (6360e0c)

      • Deprecate save_encodings_to_json, load_encodings, load_and_freeze_encodings, set_and_freeze_param_encodings and load_encodings_to_sim in favor of QuantizationSimModel.quantizer_state_dict and torch.nn.Module.load_state_dict (c34cf34)

      • save_checkpoint, load_checkpoint, check_accumulator_overflow and compute_encodings_for_sims are deprecated and will be removed in AIMET 2.44 (c34cf34)
