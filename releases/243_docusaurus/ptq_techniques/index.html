PTQ Techniques

Reference for the individual PTQ techniques AIMET implements, such as Adaptive Rounding, Sequential MSE, Cross-layer equalization, AdaScale, OmniQuant, SpinQuant, and Quantized LoRa.

📄️SpinQuant

Reduces activation outliers by inserting orthogonal Hadamard rotations that are absorbed into adjacent weight matrices, leaving the model architecture unchanged.

📄️AdaScale

Recovers accuracy lost during INT4 weight quantization, without fine-tuning, by learning per-weight scaling parameters via Blockwise Knowledge Distillation.

📄️Sequential MSE

Searches per-layer quantization encodings to minimize the mean-square error between each layer's original and quantized outputs, without training.

📄️Cross-layer equalization

Rescales weight ranges across consecutive layers so the same quantization parameters work well across all channels, reducing quantization noise.

📄️Batch norm folding

Folds batch normalization layers into the weights and biases of adjacent convolution or linear layers to eliminate unnecessary computation.

📄️Batch norm re-estimation

Re-estimates batch norm statistics from a small subset of training data, then folds the batch norm layers into the preceding convolution or linear layers.

📄️OmniQuant

Computes optimal weight quantization parameters via Learnable Weight Clipping and Learnable Equivalent Transformation, using Blockwise Knowledge Distillation.

📄️Adaptive rounding

A rounding mechanism for model weights that uses training data to adapt how weights are rounded, improving accuracy over naive nearest rounding.
