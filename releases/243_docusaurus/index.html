pip install aimet-onnx
import onnx, torch
from torchvision.models import mobilenet_v2

# Export a pretrained model to ONNX
model = mobilenet_v2(weights="DEFAULT").eval()
dummy_input = torch.randn((1, 3, 224, 224))
torch.onnx.export(model, dummy_input, "/tmp/model.onnx", dynamo=False)
onnx_model = onnx.load_model("/tmp/model.onnx")

from aimet_onnx.quantsim import QuantizationSimModel
from aimet_onnx import int8, int16
from aimet_onnx.utils import make_dummy_input

# Insert quantizers (INT8 weights, INT16 activations)
sim = QuantizationSimModel(onnx_model, param_type=int8, activation_type=int16)

# Compute quantization encodings (scale/offset) from sample data
calibration_data = make_dummy_input(onnx_model)
sim.compute_encodings(inputs=[calibration_data])
pip install aimet-torch
import torch
from torchvision.models import mobilenet_v2

# Load a pretrained model
model = mobilenet_v2(weights="DEFAULT").eval()
dummy_input = torch.randn((1, 3, 224, 224))

from aimet_torch import QuantizationSimModel

# Insert quantizers (8-bit weights, 16-bit activations)
sim = QuantizationSimModel(model, dummy_input, default_param_bw=8, default_output_bw=16)

# Compute quantization encodings (scale/offset) from sample data
def forward_pass(model):
    with torch.no_grad():
        model(dummy_input)

sim.compute_encodings(forward_pass)

What AIMET does

Everything you need to take a trained model from floating point to deployed, quantized, and accurate.

🧪
Simulate quantization

Preview quantized accuracy before deploying, by inserting quantize/dequantize operations into your model graph.

🎯
Post-Training Quantization

AdaRound, CLE, AdaScale, SeqMSE, and more — improve accuracy without retraining.

🏋️
Quantization-Aware Training

Fine-tune with quantization noise in the loop, for when PTQ alone isn’t enough.

🎛️
Mixed precision

Create mixed-precision models to trade a small size increase for better accuracy.

📦
Export

Produce a deployable, quantized ONNX model plus a JSON encodings file, ready to run via ONNX Runtime.

🧩
Two packages

aimet-onnx for fast PTQ iteration, aimet-torch for PTQ and fine-tuning-based QAT.

🤖
GenAI model quantization

Quantize LLMs and LVMs with advanced techniques like SpinQuant, AdaScale, SeqMSE, and LPBQ — with tested recipes for popular models.

📊
Analysis tools

Visualize and debug quantization sensitivity layer-by-layer with QuantAnalyzer.
